# GraphShield AI

## AI-Driven Zero-Day Intrusion Detection: Graph Neural Networks for Encrypted Network Traffic Analysis

### Project Goal

GraphShield AI is a cybersecurity research project that investigates the use of Graph Neural Networks (GNNs) for intrusion detection using flow-level network information.

The project aims to study whether representing network communication as a graph can help identify anomalous and previously unseen attack patterns without depending on decrypted packet payloads.

### Main Pipeline

Network Traffic
→ Flow-Level Data
→ Data Preprocessing
→ Graph Construction
→ Graph Neural Network
→ Anomaly / Attack Detection
→ Evaluation
→ Dashboard
